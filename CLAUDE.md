# MedReview

Evidence-grounded medication-review agent for synthetic FHIR patient records.
Educational prototype, not medical advice.

## How to work with me
- I'm learning. Explain what code does before writing it, in simple words.
- Make small changes, one step at a time. Never edit many files at once.
- Never add a new library without asking me first.
- Never edit or delete anything in data/raw/.
- Never commit .env or API keys.
- Don't put # comments in zsh terminal commands.
- If something fails, explain why before fixing it.

## Key rules of the project
- Fixed rules decide interaction flags. The LLM only explains them.
- Every claim must cite an FDA label section.
- Eval answers are never generated by an LLM.
